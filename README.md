# 법무부 정심 업무도우미

소년보호 법령 AI 업무도우미 — 등록한 자료를 근거로 답변하고, 스스로 자동학습하는 클라이언트 전용(서버 비용 0원) 챗봇 웹앱입니다.

## 주요 기능

- **자체 데이터 기반 답변**: 관리자가 등록한 법령·지침·매뉴얼(txt·md·pdf) 안에서 관련 내용을 찾아 답변
- **자동학습**: 자료를 등록하면 즉시 핵심 내용을 선(先)학습하고, 실제 질문에 답할 때마다 그 질답을 자동으로 저장해 다음부터 더 빠르고 일관되게 답변
- **관리자 모드**: 접속/관리자 비밀번호 분리, 자료 등록·삭제, 학습 로그 관리
- **비용 0원**: 서버나 외부 AI API 호출 없이 브라우저 안에서 전부 동작 (사용자 수와 무관하게 요금 없음)
- **PWA 지원**: 홈 화면에 설치 가능한 앱 아이콘 제공
- **다크모드 / 하늘색 라이트모드**, 실시간 시계, 위치 기반 날씨(선택)

## 실행 방법

### 로컬에서 바로 열기
`index.html`을 더블클릭하면 로그인·챗봇·자료 관리 기능을 바로 사용할 수 있습니다. (날씨·PWA 설치 기능은 제한됩니다.)

### 로컬 서버로 전체 기능 사용 (권장)
- **Windows**: `정심_실행.bat` 더블클릭
- **macOS/Linux**: `./정심_실행.sh` 실행

두 스크립트 모두 Python이 설치되어 있어야 하며, 로컬 서버를 띄운 뒤 브라우저를 자동으로 엽니다.

### 정적 호스팅에 배포
이 저장소의 모든 파일을 그대로 GitHub Pages, Netlify, Vercel 등 정적 호스팅에 올리면 어디서든 접속 가능한 주소로 사용할 수 있습니다. (참고: 여러 사용자가 접속해도 자료는 각자의 브라우저에만 저장되며 서로 공유되지 않습니다. 자료를 공유하려면 별도의 백엔드가 필요합니다.)

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (UI + 답변 엔진 + 관리자 기능) |
| `manifest.webmanifest` | PWA 설치 설정 |
| `sw.js` | 오프라인 캐싱을 위한 서비스 워커 |
| `icon-*.png` | 앱 아이콘 |
| `login-hero.png` | 로그인 화면 캐릭터 이미지 |
| `정심_실행.bat` / `정심_실행.sh` | 로컬 서버 원클릭 실행 스크립트 |

## 라이선스 / 주의사항

비밀번호는 브라우저 로컬 저장소에만 저장되며 별도 암호화는 되어 있지 않습니다. 민감한 실사용 환경이라면 서버 기반 인증으로 업그레이드하는 것을 권장합니다.
